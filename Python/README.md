
# Python Analysis

## Project Overview
This folder contains Python-based analysis of bank loan data to explore lending performance, loan applications, and loan quality.

## Tools & Libraries
- **Python:** Programming language for data analysis.
- **Pandas:** Data loading, manipulation, and analysis.
- **NumPy:** Numerical operations.
- **Matplotlib:** Data visualization.
- **Seaborn:** Statistical data visualization.

## Analysis Workflow

1. **Library Import:** Imported the required Python libraries.
2. **Data Loading:** Loaded the bank loan dataset using Pandas.
3. **Data Exploration:** Examined the dataset structure and records.
4. **Data Analysis:** Used Python libraries to explore loan-related information.
5. **Data Visualization:** Used Matplotlib and Seaborn for visual exploration.

## Dataset
- File: `financial_loan.csv`
- Total Records: 38,576 loan applications.

## Project File
- `bank_loan_analysis.ipynb` – Jupyter Notebook containing the Python analysis.

## Objective
To extract meaningful insights from bank loan data and support data-driven understanding of lending performance and loan quality.
