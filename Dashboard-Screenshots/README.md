# Power BI Dashboard Screenshots

This folder contains screenshots of the Bank Loan Analysis Power BI dashboard.

## Dashboard Pages

1. **Summary:** Displays key performance indicators, good loan and bad loan analysis, and loan status.
2. **Overview:** Shows loan application trends by month, state, term, employee length, purpose, and home ownership.
3. **Details:** Provides detailed loan application-level information.

These dashboards help understand loan performance, lending trends, and loan quality.
