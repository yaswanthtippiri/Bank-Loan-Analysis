
# Bank Loan Dataset

## Dataset Overview
This folder contains the financial loan dataset used in the Bank Loan Analysis project.

The dataset consists of **38,576 loan applications** and is used to analyze lending performance, loan quality, funded amounts, and repayment trends.

## Dataset Details
- **File Name:** financial_loan.csv
- **File Format:** CSV (Comma-Separated Values)
- **Total Records:** 38,576 loan applications

## Purpose
The dataset is used to:
- Analyze loan application trends.
- Evaluate good loans and bad loans.
- Examine funded amounts and amounts received.
- Identify lending patterns and loan performance.

## Usage
This dataset is used for:
- SQL queries and data analysis.
- Python analysis using Pandas, NumPy, Matplotlib, and Seaborn.
- Power BI dashboard development.
